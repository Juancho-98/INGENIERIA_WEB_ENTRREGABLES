Bienvenido a mi sitio web

Este es un ejemplo de un menú vertical básico con enlaces externos e internos.

Haz clic en los enlaces del menú para visitar Google, YouTube o ver las imágenes en esta página. Un menú vertical es una lista de enlaces colocados de manera vertical que permite navegar entre secciones o páginas. Se construye con HTML para la estructura y CSS para el diseño, y puede incluir efectos, iconos y enlaces a cualquier sitio.
